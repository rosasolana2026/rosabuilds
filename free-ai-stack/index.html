Installation Guide

Get it running in under an hour.

Step-by-step. macOS (Apple Silicon) focus, Linux notes included.

1
Install Ollama + pull Qwen3
Local LLM inference. Takes ~5 min to download the model.
brew install ollama ollama serve & ollama pull qwen3:8b

Test it: ollama run qwen3:8b "say hello". You should get a response in under 2 seconds on M2+.

Linux: curl -fsSL https://ollama.com/install.sh | sh. Requires 8GB RAM minimum, 16GB recommended.
2
Install Kokoro TTS
82M parameter voice model. Runs on CPU, no GPU needed.
pip3 install kokoro-onnx soundfile python3 -c "from kokoro_onnx import Kokoro; k=Kokoro('kokoro-v0_19.onnx','voices.json'); print('ok')"

Download model weights from hexgrad/Kokoro-82M on HuggingFace. Place kokoro-v0_19.onnx and voices.json in your working directory.

# Generate audio from kokoro_onnx import Kokoro import soundfile as sf k = Kokoro("kokoro-v0_19.onnx", "voices.json") samples, sr = k.create("Hello from Rosa.", voice="af_nova", speed=1.0, lang="en-us") sf.write("output.wav", samples, sr)
3
Install LTX-Video
Text-to-video and image-to-video, local.
pip3 install ltx-video # Download model (13GB — do this once) python3 -c "from ltx_video import download_model; download_model()"

Generate a clip:

from ltx_video import LTXPipeline pipe = LTXPipeline.from_pretrained("Lightricks/LTX-Video") video = pipe(prompt="A robot writing code at a desk, cinematic", num_frames=49) video.save("output.mp4")
Needs 16GB RAM on Apple Silicon or 8GB VRAM on Nvidia. Slower on CPU — expect 3–5 min per 49-frame clip.
4
Configure Codex CLI with Ollama
Agentic coding loop, no API key required.
npm install -g @openai/codex # Point Codex at local Ollama export OPENAI_BASE_URL=http://localhost:11434/v1 export OPENAI_API_KEY=ollama # any string works codex --model qwen3:8b "add error handling to server.js"

Codex will read your files, plan changes, and apply them. Same loop as the paid version — just slower inference. For serious coding, Ollama on local GPU or cloud (still free with free tiers) is faster.

5
Wire it into OpenClaw
Set Ollama as fallback model; configure tool paths.

In your OpenClaw config or MEMORY.md, add:

# MEMORY.md — Model Priority Primary: Claude Sonnet 4.6 (when credits available) Fallback: ollama/qwen3:8b (zero cost, always available) # Set fallback in openclaw config: openclaw config set model.fallback ollama/qwen3:8b
OpenClaw will automatically route to Ollama when the primary provider is rate-limited or offline. Your agent keeps running — at zero cost.
